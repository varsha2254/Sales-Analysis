# Sales Analysis

## About the Project

This project is about analyzing **Ferns and Petals (FNP) sales data**.

The main purpose of this project is to understand sales, customers, products, and orders.

## Dataset

The project contains three datasets:

* `customers.csv` – Customer details
* `orders.csv` – Order details
* `products.csv` – Product details

## Analysis

In this project, I analyzed:

* Total sales
* Customer details
* Product sales
* Orders
* Sales by occasion
* Sales by category
* Customer purchasing patterns

## Tools Used

* Microsoft Excel
* CSV
* Data Analysis
* Data Visualization
